1. Sistemas e estruturas cristalinas. Materiais cristalinos têm organização atômica periódica descrita por uma célula unitária com arestas a, b, c e ângulos α, β, γ. Os sistemas cobrados pela banca:

Sistema Arestas Ângulos
Cúbico a = b = c α = β = γ = 90°
Tetragonal a = b ≠ c α = β = γ = 90°
Ortorrômbico a ≠ b ≠ c α = β = γ = 90°
Hexagonal a = b ≠ c α = β = 90°, γ = 120°
Romboédrico (trigonal) a = b = c α = β = γ ≠ 90°

Mnemônico: o hexagonal é o único com γ = 120°; o cúbico é o único "tudo igual, tudo 90°"; o tetragonal é o cúbico "esticado" (a = b ≠ c).

2. Estruturas metálicas típicas. Memorize a tabela:

Estrutura Átomos/célula Nº coordenação Fator de empacotamento Exemplos
CCC (cúbica de corpo centrado) 2 8 0,68 Fe-α (ferrita), Cr, Mo, W
CFC (cúbica de face centrada) 4 12 0,74 Fe-γ (austenita), Al, Cu, Ni, latão-α
HC (hexagonal compacta) 6 12 0,74 Zn, Mg, Ti-α

Densidade teórica: ρ = n·A / (V_C·N_A), onde n = átomos por célula, A = massa atômica (g/mol), V_C = a³ (cúbicas), N_A ≈ 6,0×10²³. Cuidado com unidades: 1 nm = 10⁻⁹ m; o resultado em g/m³ divide-se por 1000 para kg/m³... não! g → kg divide por 1000, e a banca costuma dar alternativas com fatores 2× e 4× para pegar quem erra o número de átomos por célula (CCC → n = 2; CFC → n = 4).

3. Alotropia do ferro. O ferro puro é CCC (ferrita α) até 912 °C, CFC (austenita γ) de 912 °C a 1394 °C, e volta a CCC (ferrita δ) até a fusão a 1538 °C. Como a CFC é mais compacta (FEA 0,74 > 0,68), a transformação α → γ no aquecimento causa uma CONTRAÇÃO brusca de volume (e γ → δ causa expansão). É isso que a dilatometria detecta: o comprimento cresce quase linearmente com T e sofre uma pequena e brusca redução a 912 °C.

4. Difusão. Transporte de átomos por saltos ativados termicamente. O coeficiente de difusão segue Arrhenius:

D = D₀ · exp(−Q / RT) — Q = energia de ativação (J/mol); R = 8,314 J/mol·K; T em kelvin!

A profundidade de penetração (cementação, descarbonetação) segue a relação parabólica x² = D·t (ou x² = k·D·t). Receita de prova para comparar duas temperaturas com mesmo tempo:

x₂²/x₁² = D₂/D₁ = exp[−(Q/R)·(1/T₂ − 1/T₁)]

Passos: (i) converta °C → K; (ii) calcule Q/R; (iii) aplique ln nos dois lados se a incógnita for T. Difusão aumenta exponencialmente com T — é o fato físico por trás da curva em C das transformações (Módulo 3).

5. Encruamento (deformação a frio). A deformação plástica ocorre pelo movimento de discordâncias (deslocações). Ao deformar a frio, a densidade de discordâncias cresce (de ~10⁶ para ~10¹⁰–10¹² cm/cm³); as discordâncias geradas interagem entre si e com átomos de soluto, travando-se mutuamente. Resultado: aumento do limite de escoamento e da dureza, queda da ductilidade. Por isso, dobrar uma barra recozida e depois tentar desdobrá-la exige esforço maior — a região deformada encruou. Em solução sólida (ex.: Cu-Zn), os átomos de soluto ancoram adicionalmente as discordâncias (endurecimento por solução sólida + encruamento).

6. Recuperação, recristalização e crescimento de grão. O recozimento de um metal encruado passa por três etapas: - Recuperação: rearranjo/aniquilação parcial de discordâncias; alivia tensões, dureza quase não cai. - Recristalização: nucleação e crescimento de novos grãos livres de deformação; a dureza e o limite de escoamento caem para os valores do material recozido. Temperatura típica: T_recr ≈ 0,3–0,5·T_fusão (em K). - Crescimento de grão: em temperaturas mais altas/tempos longos, os grãos crescem, reduzindo ainda mais a dureza (Hall-Petch).

Regras de ouro da recristalização (caem literalmente em prova): - Maior deformação prévia ⇒ menor temperatura de recristalização (mais energia armazenada = mais força motriz) e menor tamanho de grão recristalizado (mais sítios de nucleação). - Menor deformação ⇒ precisa de T maior e gera grão maior. - Existe uma deformação crítica (~2–5%) abaixo da qual não há recristalização. - Hall-Petch: σ_e = σ₀ + k·d^(−1/2) — grão menor ⇒ limite de escoamento maior.

7. Consequência prática (questões de "escolha do material"). Para uma mesma liga: recozido < pouco encruado < muito encruado, em resistência. Se o requisito é suportar carga com a menor massa, escolha o material mais encruado (mais resistente por unidade de área e, na laminação, o de menor espessura final). Se o requisito é conformar facilmente, escolha o recozido/recristalizado em temperatura alta (menor dureza possível — recristalização completa + crescimento de grão).

Números-chave do módulo: Fe-α CCC até 912 °C; Fe líquido a 1538 °C; FEA CCC = 0,68, CFC = 0,74; CCC n = 2, CFC n = 4; T_recr ≈ 0,4·T_f (K); R = 8,314 J/mol·K.
