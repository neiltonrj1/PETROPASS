Q1 — letra C. Cadeia da indústria: upstream = exploração e produção; midstream = processamento, armazenagem, transporte e comercialização; downstream = operações pós-produção até o ponto de venda (refino/distribuição/varejo). As alternativas com "boat/water flow" brincam com o sentido literal de "corrente do rio" — pegadinha. Gabarito oficial: C.

Q2 — letra A. Em relatórios de mercado, quarter = trimestre (a quarta parte do ano): "the coming two quarters" = os próximos dois trimestres. As demais exploram outros sentidos de quarter (15 minutos, moeda de 25 cents, ¼ de galão) fora de contexto. Gabarito oficial: A.

Q3 — letra C. Easing = abrandamento: tensões geopolíticas em processo de alívio → alleviated. Enhanced (intensificadas) inverte o sentido; jeopardized = ameaçadas. Gabarito oficial: C.

Q4 — letra B. Output = produção (product); mild = ameno (gentle); balance = equilíbrio (equilibrium); inventories = estoques (stocks). "Lists" só serviria para "inventário" como lista de itens — não é o sentido de estoques globais de petróleo.

Q5 — letra B. "Is anticipated/projected/expected to + infinitivo" são projeções: verbo no presente (is/will be) apontando para acontecimentos futuros → present time and future time. Não expressam desejo, promessa nem compromisso do autor — apenas previsão. Gabarito oficial: B.

Q6 — letra C. Take stock (of) = fazer um balanço, avaliar globalmente uma situação (metáfora do inventário). "Reevaluate controversial decisions" restringe demais; "discard/get rid of" são ações que não estão na expressão.

Q7 — letra C. Stem (como verbo) = conter, frear ("stem emissions") → sinônimo de restrain. Pares errados: channel (canalizar) ≠ hinder (atrapalhar); stark (duro, contundente) ≠ dubious; pledged (comprometeu-se) ≠ refused; bold (ousado) ≠ fearful (medroso) — este é antônimo.

Q8 — letra E. Should + passiva expressa recomendação enfática do autor (os programas "devem ser" avaliados continuamente) → strong recommendation. Não é habilidade (can), probabilidade (may/might) nem permissão.

Q9 — letra D. Point out = apontar, assinalar → report ✔. Erros: set out = apresentar (≠ discarded); run out = esgotar-se (≠ prevails); build on = aproveitar como base (≠ reject); set up = criar (≠ canceled).

Q10 — letra A. Turn down = recusar (refuse). O contexto confirma: "I couldn't turn down the great starting salary" = não pude recusar o ótimo salário. Take/accept inverteriam a lógica do "couldn't".

Q11 — letra B. Headquarters = sede, matriz → main office ✔. As demais invertem relações: major = principal (mesma ideia de main); smart = intelligent (sinônimos, não antônimos); enhance = aumentar (oposto de reduce); prospective = futuro/potencial (oposto de former = antigo).

Q12 — letra D. As well as = "bem como", adição ✔. Although/even though = concessão; because of = causa; but = contraste.

Q13 — letra E. Given that = "considerando que / levando em conta que" → taking into account that ✔ (valor causal-argumentativo). Even though/despite são concessivos (inverteriam a relação); because of the fact that até se aproxima, mas a equivalência exata consagrada pela banca é a alternativa E. Gabarito oficial: E.

Q14 — letra D. Pick up = ganhar ritmo, aumentar (o crescimento econômico "has picked up"); driven by = impulsionado/motivado por (as ambições de Pequim, motivadas pela poluição do ar) → increased – motivated by. Gabarito oficial: D.

Q15 — letra D. Thriving = prosperando, em pleno desenvolvimento → sinônimo de developing ✔. Rife = abundante (oposto de scarce); claimed = alegado (≠ hidden); flat = estável (≠ high); surge = aumento súbito (sinônimo de increase, não antônimo). Gabarito oficial: D.

Q16 — letra A. Can de possibilidade equivale a may: "pode ser aplicado". Has to/ought to adicionam obrigação/recomendação; will definitely adiciona certeza; might occasionally enfraquece e restringe ("ocasionalmente") — mudam o sentido.

Q17 — letra E. O comando pede ANTÔNIMOS: pressing = urgente ↔ trivial = banal ✔. Os demais pares são sinônimos ou quase: tough≈complicated, clogged≈crowded, disrupted≈destroyed (interrompido/danificado), breaches≈violations.

Q18 — letra D. So = "então/portanto", conclusão ✔ ("você não sabe onde está a demanda, então é complicado"). But = contraste; rather than = preferência/substituição; while = simultaneidade/contraste; such as = exemplificação.
